# oop-cpp

Object-oriented programming in C++.

## Files

- `matrix_multiplication.cpp` — Matrix multiplication using a `Matrix` class
- `constructor_overloading.cpp` — Complex number addition with overloaded constructors
- `friend_function.cpp` — Greatest of two numbers across classes using a friend function
- `string_operator_overloading.cpp` — Custom `String` class (`+`, `=`, `<=`, length, case conversion)
- `virtual_list_stack_queue.cpp` — Abstract `List` base class with `Stack` and `Queue` implementations
- `function_template.cpp` — Function template for squaring numbers across data types
- `class_template.cpp` — Class template with constructor and destructor
- `file_whitespace_removal.cpp` — Remove whitespace characters from a text file
- `student_file_io.cpp` — Read and write `Student` records using file streams
- `array_bounds_exception.cpp` — Dynamic array with out-of-bounds exception handling

## Run

```bash
g++ constructor_overloading.cpp -o constructor_overloading
./constructor_overloading
```
